🚀 Data Migration — Doosre Software Pe Jaana

Marg, Tally, Vyapar, ya kisi bhi accounting software mein data le jaana ho to neeche ke exports use karo. Har format alag software ke liye optimize hai.
📋 Migration Steps
1 Full Backup (JSON) lo — ye Div ka native format hai, wapas restore bhi kar sakte ho
2 Naye software ke hisaab se CSV ya Excel file download karo neeche se
3 CSV file naye software mein Import / Upload karo (columns manually map karne pad sakte hain)
4 Hindi names ke liye Excel (UTF-8 BOM) wala format use karo — seedha Excel mein khulega

📲 App Install Karo — Mobile & Desktop

Div Manager ko apne phone ya computer pe seedha install karo — bilkul kisi bhi app jaisa. Internet nahi hai tab bhi kaam karta hai.
✅ App already install hai! Home screen pe dekho.
Manual Install kaise karein:
iPhone / iPad (Safari):
1. Safari mein yeh page kholo
2. Neeche Share button (↑) dabao
3. "Add to Home Screen" select karo
4. "Add" dabao — ho gaya! 🎉
Android (Chrome):
1. Chrome mein yeh page kholo
2. Upar teen dots (⋮) dabao
3. "Add to Home screen" ya "Install app" select karo
4. "Install" dabao — ho gaya! 🎉
Desktop (Chrome / Edge):
1. Address bar ke right side mein install icon (⊕) dikhai dega
2. Usse click karo aur "Install" dabao
3. App shortcut desktop pe aa jayega 🎉
� Kaam karta hai: Android, iPhone, iPad, Windows (Chrome/Edge), Mac (Chrome)
